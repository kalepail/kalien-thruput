# shared/thruput

Thruput code shared by the browser, the Worker and the CLI. Owner: the contract agent.

- `claim.ts`: the claim digest the player signs and the player's pubkey-account address.
  Byte-exact with the score contract (`kalien-contract/contracts/kalien_score/src/claim.rs`).
  - `claimMessage({ networkHash, scoreContract, seedId, tape })` → 32-byte digest. Sign it with
    Ed25519 (`ed25519.sign(digest, secret)` or `new PrivateKeySigner(secret).sign(digest)`).
  - `pubkeyAccountAddress(pubkey)` → `0x…` address of the nonce-0 pubkey account. The contract
    mints KALIEN there. It equals `createPubkeyAccount({ signer }).address`.
  - `tapeHash(tape)` = `sha256(tape)`, the dedupe key (`is_claimed`).
- `claim-vectors.json`: test vectors. `bun test shared/thruput/claim.test.ts` checks the TS side
  (also against `@thruputchain/client`); `cargo test` in `kalien-contract/` checks the Rust side.
- `bindings/`: generated by `thruput codegen ts` (run `kalien-contract/scripts/build.sh`). Do not edit.
  `KalienScore.v0_1.submitScore.call(...)`, `ERC20.v0_1.getBalanceOf.view(...)`, and event
  descriptors such as `kalien_score.v0_1.implementation.ScoreSubmitted`.
- `deployments/devnet.json`: network hash, RPC URL and contract addresses of the current devnet
  deploy. Rewritten by `kalien-contract/scripts/deploy-devnet.sh`.

Example (relay side, as in `kalien-contract/scripts/kalien.ts`):

```ts
const call = KalienScore.v0_1.submitScore.call({
  contract: scoreAddress,
  gasLimit: gasAmount(limit - 100_000n),
  args: { playerPubkey: fixedBytes(pubkey, 32), seedId: BigInt(seedId), tape, signature: fixedBytes(sig, 64) },
});
const res = await relayWallet.executeCallsAndWait({ calls: [call] as const, gasLimit: gasAmount(limit) });
// limit = 3_000_000n + 2_200n * BigInt(frameCount)
```
