# Shared modules

TypeScript shared by the browser (`src/`), the Worker (`worker/`), the CLI (`cli/`), and the
contract scripts (`kalien-contract/scripts/`).

## Layout

- [`thruput/`](thruput/README.md): everything that must match the Thruput contracts byte for byte.
  - `claim.ts`: the claim digest the player signs, the tape hash, and the player's pubkey-account
    address. Vectors: `claim-vectors.json` (checked by TS and Rust tests).
  - `kalien.ts`: chain helpers over `@thruputchain/client` (reads, `ScoreSubmitted` event pages,
    relay submit with an `onSigned` hook, seed creation, gas limit, error table, padding check).
  - `bindings/`: TS bindings generated by `thruput codegen ts` from the contracts. Do not edit.
  - `deployments/futurenet.json`: network hash, RPC URL, and contract addresses of the current Futurenet
    deployment. The Worker and the scripts read it; it changes after every Futurenet wipe.
  - `test-data/`: recorded RPC responses for the offline tests.

Tests: `bun test shared/thruput/` (`KALIEN_LIVE=1` adds a live Futurenet read).

The Stellar/Soroban helpers that lived in `shared/stellar/` (StrKey parsing, ZK journal
packing, Soroban bindings) were removed with the Thruput port; see `docs/archive/zk/` for the old
system.
